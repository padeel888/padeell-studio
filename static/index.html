QUICK START

Panduan menggunakan Padeel Studio

  1. Buat API key pada Creator Dashboard dengan izin Assets yang sesuai, lalu masukkan User ID atau Group ID.
  2. Masukkan maksimal 150 file audio sumber dalam satu batch. Sesuaikan edit massal atau per lagu.
  3. Centang pernyataan izin penggunaan audio, lalu tekan Upload antrean. Website mengunggah satu aset per permintaan melalui Open Cloud resmi.
  4. Setelah hasilnya tersedia, salin rbxassetid://ASSET_ID dari library. Simpan juga CSV sebagai backup.

Roblox membatasi durasi hingga 7 menit dan file output hingga 20 MB. Kuota akun tidak dapat dilewati. Jika upload tertunda, gunakan tombol Cek status sebelum mengulang agar tidak menghasilkan aset ganda.
